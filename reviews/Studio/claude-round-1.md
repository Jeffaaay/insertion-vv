# Studio 版审阅（Claude）

**核验范围：** 我看了 overview、preview，并从视频里抽了 1.4 / 2.24 / 7.96 / 8.0 / 10.0 s 共 5 帧；读了 `studio_scene.py` 的几何和 `set_pose`。另外用公开的 nominal truth（`selected-traces.zip`）核对了画面底部的数值。

## 数据与时序：通过

- **几何对齐正确。** 针尖圆锥的顶点就是记录的 qpos，样本顶面等于 tissue_z，300 µm 标记画在过针轴的 y=0 剖面上。
- **两段时序正确。** 前 200 帧每帧间隔 40 tick（1 倍速）；后 100 帧覆盖源时间 2.0–2.99 s（0.25 倍速）。8.0 s 处正确切到 `0.25× / SLOW REPLAY`，源时间显示 2.00 s。
- **镜头切换没有干扰插入段。** 镜头在源时间 1.0–1.92 s 之间推进，插入从 2.0 s 才开始。
- **底部指标与 truth 逐点一致。** 我抽查了 0 / 1.4 / 2.0 / 2.24 / 2.5 / 3.6 s 六个时刻，深度、接触力、误差全部吻合（例如 2.24 s 为 −125.1 µm，2.5 s 为 +249.3 µm / 5.37 mN / −50.74 µm）。
- **免责说明到位。** 每帧页脚都注明了"示意装置、软接触、不声称穿刺或硬件"。

## 画面：比上一版好懂得多，但核心镜头还没达到"看到针进入材料"

**1.【主要】剖切面看不出是剖切面。**
剖面和外表面用的是同一种不透明青色，所以：
- 2.24 s 时针还在表面上方 125 µm，但在俯视角度下，针尖投影落在顶面区域里，看起来像已经扎进去了；
- 真正插入以后，针看起来像是贴着一个实心块的正面往下滑。

几何本身没错，但"进入材料"这个信息没有传达出来。修法（只需重新渲染）：
- 剖面换成截面材质：颜色更深或更饱和，加剖面线或轻微半透明，让它一眼看出是"切开的"；
- 在剖面顶边（也就是材料表面）加一条细亮线，让针尖在表面上方还是下方一目了然；
- 可选：把特写镜头的俯角从约 21° 降到 10° 左右，减少表面上方的针尖投影到顶面上的错觉。

**2.【次要】立柱上的 "Z / 01" 文字是镜像的，还被滑块挡住了一部分。** 把文字绕 z 轴转 180°，或者换个位置。

**3.【次要】缺少尺度参照。** 全景图里没有任何比例尺。这套装置按真实毫米尺寸建模，整体只有约 1 cm 高，但看起来像一台台式仪器，观众会误判运动幅度。在全景加一个"5 mm"比例尺，并给特写里样本右侧的刻度尺标上"0.2 mm / tick"。

**4.【次要，文案】慢放段仍沿用 "Stay with the surface." 这个标题。** 和"02 / INSERTION DETAIL"不太对应，可以换成描述插入的标题。
